FAQ

常见问题。

双击运行时提示“未知发布者”怎么办？

两款软件暂未购买代码签名证书，个别杀毒软件可能提示。请点「更多信息 → 仍要运行」；首次启动因杀毒扫描可能稍慢，之后秒开。两款软件均完全开源，可随时到 GitHub 查看源码。

GitHub 下载慢或打不开怎么办？

GitHub 在国内下载可能较慢，若打不开可多试几次，或使用加速镜像。下载后可用 Release 页面附带的 SHA256 值校验文件完整性（流晷计时器每个 Release 均附有校验值）。

需要安装吗？怎么卸载？

都不需要安装：WorkAid 与流晷计时器的文件夹版解压后双击 exe 即可使用。卸载时直接删除软件文件夹即可；流晷计时器的预设与分类保存在 %APPDATA%\流晷计时器\，一并删除即完全卸载。

会收集我的数据吗？

不会。两款软件均不联网：WorkAid 的所有文档在本地处理，流晷计时器的倒计时、预设、悬浮窗位置全部存在本机。

Word 转 PDF 需要装 Office 吗？

WorkAid 中仅「Word 转 PDF」「PPT 转 PDF」需要本机已安装 Microsoft Office 或 WPS（支持双引擎）；其余功能如 PDF 转 Word、加水印、合并拆分、图片工具等均为纯本地实现，无需任何办公软件。
